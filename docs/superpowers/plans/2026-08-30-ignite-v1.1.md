# Ignite v1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the broken cancel-build call and cover the parts of the Codemagic API a CI/CD admin app needs — step logs, caches, variables, artifact sharing — while making the home screen match what the README promises.

**Architecture:** Purely additive against the existing layering: models describe API JSON, `CodemagicApi` owns HTTP, Riverpod providers wrap the service, pages consume providers. Three new pages, no restructuring.

**Tech Stack:** Flutter 3.41.6, Riverpod 2.6, GoRouter 14.8, http, shimmer, fl_chart, flutter_animate.

**Spec:** `docs/superpowers/specs/2026-08-30-ignite-v1.1-design.md`

## Global Constraints

- Base URL `https://api.codemagic.io`; auth header `x-auth-token`.
- `GET /builds` supports `appId`, `limit`, `status`, `branch`, `workflowId`, `skip`. **`page` is ignored — never send it.**
- `GET /apps/:id/variables` returns a **bare JSON array**, not an object.
- `GET /builds/:id/step/:stepId` returns **`text/plain`**, not JSON.
- `POST /builds/:id/cancel` returns **208** when the build already finished — that is success, not an error.
- Build `status` values: `finished` (success), `failed`/`error`, `building`/`preparing`/`publishing` (running), `canceled`/`cancelled`.
- `buildActions[i].status` values: `success`, `failed`, `skipped`, `canceled`.
- Artefact JSON uses the British key `artefacts`; its `path` field is the `secureFilename` used by the public-url endpoint.
- No widget tests. Unit tests cover pure logic only, run with `flutter test`.
- Analyzer must end at 0 issues (`flutter analyze`).

**Interfaces:**

- Produces: `getBuilds({String? appId, int? limit, String? workflowId, String? status, String? branch, int skip = 0})`.

- [ ] **Step 1: Rewrite `cancelBuild` to POST**

```dart
  Future<void> cancelBuild(String buildId) async {
    final uri = Uri.parse('$_base/builds/$buildId/cancel');
    final res = await http.post(uri, headers: _headers);
    // 208 Already Reported = the build had already finished. Not an error.
    if (res.statusCode == 208) return;
    if (res.statusCode >= 400) {
      throw CodemagicApiException(res.statusCode, _messageOf(res));
    }
  }
```

- [ ] **Step 2: Add the shared error-message reader used above**

```dart
  String _messageOf(http.Response res) {
    try {
      final body = jsonDecode(res.body) as Map<String, dynamic>;
      return body['message']?.toString() ?? body['error']?.toString() ?? 'HTTP ${res.statusCode}';
    } catch (_) {
      return 'HTTP ${res.statusCode}';
    }
  }
```

- [ ] **Step 3: Replace `page` with `skip` in `getBuilds`**

Swap the `int page = 0` parameter for `int skip = 0` and the body line
`if (page > 0) params['page'] = page.toString();` for
`if (skip > 0) params['skip'] = skip.toString();`. Add a `String? branch`
parameter that sets `params['branch']` when non-null.

```dart
  /// For endpoints returning text/plain (step logs).
  Future<String> _getText(String path) async {
    final res = await http.get(Uri.parse('$_base$path'), headers: _headers);
    if (res.statusCode >= 400) {
      throw CodemagicApiException(res.statusCode, _messageOf(res));
    }
    return res.body;
  }

  /// For endpoints returning a bare JSON array (variables).
  Future<List<dynamic>> _getList(String path) async {
    final res = await http.get(Uri.parse('$_base$path'), headers: _headers);
    if (res.statusCode >= 400) {
      throw CodemagicApiException(res.statusCode, _messageOf(res));
    }
    final decoded = jsonDecode(res.body);
    if (decoded is List) return decoded;
    if (decoded is Map<String, dynamic>) {
      for (final v in decoded.values) {
        if (v is List) return v;
      }
    }
    return const [];
  }
```

- [ ] **Step 2: Implement the build-detail and step-log calls**

  Future<CmBuild> getBuildDetail(String buildId) async {

    return CmBuild.fromJson(data['build'] as Map<String, dynamic>);

- [ ] **Step 3: Implement artifact public-url, caches and variables**

```dart
  Future<String> createArtifactPublicUrl(String path, DateTime expiresAt) async {
    final data = await _post('/artifacts/$path/public-url', {
      'expiresAt': expiresAt.millisecondsSinceEpoch ~/ 1000,
    });
    final url = data['url']?.toString();
    if (url == null || url.isEmpty) {
      throw const CodemagicApiException(500, 'No public URL returned');
    }
    return url;
  }

  Future<List<CmCache>> getCaches(String appId) async {
    final data = await _get('/apps/$appId/caches');
    final caches = data['caches'] as List? ?? [];
    return caches.map((c) => CmCache.fromJson(c as Map<String, dynamic>)).toList();
  }

  Future<void> deleteCache(String appId, String cacheId) =>
      _delete('/apps/$appId/caches/$cacheId');

  Future<void> deleteAllCaches(String appId) => _delete('/apps/$appId/caches');

  Future<List<CmVariable>> getVariables(String appId) async {
    final list = await _getList('/apps/$appId/variables');
    return list.map((v) => CmVariable.fromJson(v as Map<String, dynamic>)).toList();
  }

  Future<void> addVariable(String appId, CmVariable v) async {
    await _post('/apps/$appId/variables', v.toJson());
  }

  Future<void> updateVariable(String appId, CmVariable v) async {
    await _put('/apps/$appId/variables/${v.id}', v.toJson());
  }

  Future<void> deleteVariable(String appId, String variableId) =>
      _delete('/apps/$appId/variables/$variableId');
```

Add the `_put` helper alongside `_post`, and relax `_delete` so a 202 with an
empty or non-map body does not throw.

```dart
List<CmApplication> filterApps(List<CmApplication> apps, String query) {
  final q = query.trim().toLowerCase();
  if (q.isEmpty) return apps;
  return apps.where((a) {
    final name = a.appName.toLowerCase();
    final repo = (a.repositoryUrl ?? '').toLowerCase();
    return name.contains(q) || repo.contains(q);
  }).toList();
}
```

`latestBuildsProvider` issues a single unfiltered `getBuilds(limit: 100)` and
folds it into a map keeping the newest build per `appId`, so the home list costs
one request rather than one per app.
